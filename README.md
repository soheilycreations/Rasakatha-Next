# Rasakatha.lk storefront

Next.js 16 (App Router) + Tailwind v4 + Supabase, deployed on Vercel.

```bash
npm install
cp .env.example .env.local   # fill in the values
npm run dev
```

## Domain setup (rasakatha.lk)

1. In Vercel → Project → Settings → Environment Variables (Production) set
   `NEXT_PUBLIC_SITE_URL=https://rasakatha.lk`, then redeploy.
2. Vercel → Settings → Domains: add **`rasakatha.lk`** (primary) and **`www.rasakatha.lk`**.
   Set `www.rasakatha.lk` to *redirect to* `rasakatha.lk` (308), so the apex is the canonical host.
3. DNS: `A rasakatha.lk → 76.76.21.21`, `CNAME www → cname.vercel-dns.com` (or use the values Vercel shows).
   Lower the TTL a day before switching so a rollback is quick.
4. While the site is on `*.vercel.app`, every response carries `X-Robots-Tag: noindex`
   (see `next.config.ts`); it stops applying automatically once traffic arrives on rasakatha.lk.

### Old WooCommerce URLs

Old product/category/shortlink URLs 308-redirect to the new pages:

| Old | New |
| --- | --- |
| `/books/<slug>`, `/product/<slug>` | `/book/<id>-<slug>` |
| `/product-category/<slug>` | `/category/<slug>` (or `/categories` when it has no clean match) |
| `/?p=<id>`, `/?post_type=product&p=<id>` | `/book/<id>-<slug>` |
| `/shop`, `/my-account`, `/about-us`, `/contact-us`, … | see `redirects()` in `next.config.ts` |

Slug data lives in `src/lib/data/legacy-*.json`, generated by
`scripts/extract-legacy-urls.mjs` (from the WooCommerce SQL dump) and
`scripts/build-legacy-maps.mjs`. Handlers: `src/app/legacy/**`.

## Environment variables

See `.env.example`. Analytics and Search Console are optional and only load when set:
`NEXT_PUBLIC_GA_ID`, `NEXT_PUBLIC_META_PIXEL_ID`, `NEXT_PUBLIC_GSC_VERIFICATION`.

## Database

SQL files in `supabase/` are run by hand in the Supabase SQL Editor.
